# CL-MQTT - Common Lisp MQTT client

I made this to learn MQTT.
Used without issues for 1+ year with zigbee2mqtt on SBCL aarch64.

Also runs on CCL for 32-bit ARM, see `ccl` branch.

See my [hal9k](https://github.com/narvalotech/hal9k/blob/a649d22f2e8e2dc0770c14eed6c73bf7f5d04f69/home.lisp#L465) repo for example usage.
